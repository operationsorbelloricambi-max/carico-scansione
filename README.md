# Carico a scansione

Pagina web per spuntare la merce in arrivo leggendo i codici a barre con la fotocamera del telefono o con un lettore.

Questo repository contiene **solo la pagina** (nessun dato): è pubblico perché viene servito con GitHub Pages.
Il codice si modifica nel progetto principale (privato) e si copia qui con `pubblica-pagina.sh`: non modificare qui a mano.

Lettura dei codici a barre: libreria [html5-qrcode](https://github.com/mebjas/html5-qrcode) (licenza Apache 2.0, vedi `html5-qrcode.LICENSE`).
